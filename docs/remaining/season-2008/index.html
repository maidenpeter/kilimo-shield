5. Daily rainfall monitoring

How this was made

  • Command: python -m agroshield_platform.simulate --year 2008 (or python tools/sim/season.py). Generated 2026-11-01T15:13:32+00:00 (UTC).
  • Each step calls the platform's own services (enrolment, M-Pesa, settlement, the daily job, monitoring, approval, payment, SMS outbox, missed-payout reports, bordereaux, reinsurer summary). Prices, triggers and payouts are not re-calculated here.
  • A simulated clock stands in for the time of day inside the platform while the replay runs, so every record carries the replayed date. M-Pesa is the built-in simulator and SMS is log-only, whatever the settings say.
  • Rainfall: CHIRPS v2.0 daily (committed record), data/raw/chirps/ward-a.csv, SHA-256 264b15782ccb9200f65f8981e5812921e0c39e08de47939865910b7a3da5ddf2. Index B-1.2.0.
  • Settings fingerprints: pilot.yaml 622f69d948a9, wards.yaml 5d53a22fa76e, phenology.yaml 5d36f0cdf5f2, product.yaml 9d83169771bf.
  • Everything in the season is in season.json.
