Method

Phase rainfall R_p = sum of daily rain in phase p (days < {{ r.daily_min_mm }} mm count 0, days capped at {{ r.daily_cap_mm }} mm) Phase payout f_p = clip((trigger_p - R_p) / (trigger_p - exit_p), 0, 1) Season payout P = sum_p weight_p * f_p (share of sum insured, at most 1) Burn cost expected loss = mean P over all seasons; 1-in-10 = 90th pct; 1-in-20 = 95th pct Gross premium (expected loss + risk margin) / (1 - sum of loadings)

Percentile levels are resolved from this ward's own seasons over {{ r.calibration.start_year }}–{{ r.calibration.end_year }}. Because that window overlaps the backtest, the triggers are fitted in-sample; hold out recent years in product.yaml to test out of sample. CHIRPS daily values are disaggregated from five-day totals, so the index only ever uses multi-week phase sums.
