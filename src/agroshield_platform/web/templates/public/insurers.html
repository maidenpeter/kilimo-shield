Audit trail

  • Every pricing run saves a manifest: index version, config hashes, input checksums, code version and a results hash.
  • Every ward trigger calculation is versioned and logged with the data it used.
  • Every policy, payment, approval, hold and payout is an audit event with who and when.
  • Bordereaux come with a manifest and a checksum for each file.
  • Missed-payout reports from farmers are kept and reviewed, so basis risk can be measured over time.

Kenya's draft index insurance regulations, reported as a 10-day payout rule{{ ui.cite(3) }}, were still a draft in February 2026{{ ui.cite(4) }}. The payout clock in the workspace is built around that standard.

Still to be agreed

We would rather you see the gaps now than in due diligence.

  • Partner insurer: to be named. No insurer, reinsurer or regulator has approved this product.
  • Pilot wards: placeholders in Nakuru County; the pilot SACCO is not yet chosen.
  • Loadings and margin: placeholders for the insurer to set.
  • Subsidy terms: to be confirmed with the programme and the insurer.
  • Consent wording: pending legal review and Kiswahili review; live enrolment is blocked until then.
  • Payments: M-Pesa sandbox only; real M-Pesa payouts are switched off.
  • Weather advisories by SMS: off until written permission from the Kenya Meteorological Department.
  • Livestock: in development, not quotable.
